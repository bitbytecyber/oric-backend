# org/seed: NED faculty directory seed

These files are generated by `tools/build_directory.py`. Don't edit them by hand. Change the script, then run it again.

| File | Columns |
|---|---|
| `faculties.csv` | `code,name,short_name,dean_email` |
| `departments.csv` | `code,name,faculty_code,chair_email,co_chair_emails,website` |
| `people.csv` | `email,full_name,designation,department_code,is_phd,employee_id,phone,aliases,email_source,source` |
| `oric_staff.csv` | `email,full_name,title,role,department_code,phone_ext,order` |

All files are UTF-8 CSV with a header row. Fields that hold more than one value (`co_chair_emails`, `aliases`) use `;` as the separator.

## Sources

1. **Department websites.** The script reads the teaching-staff page of every department (`https://<sub>.neduet.edu.pk/...`) and of TIEST CS&T. It also opens the CIS profile pages to look for emails. The page paths and the parser mode for each department are listed in the `DEPARTMENTS` table in the script.
   - Only teaching faculty are kept: Lecturer up to Professor, plus Chair, Dean and VC/PVC.
   - Lab engineers, IT managers, PAs, adjunct and visiting staff are dropped.
   - If a page can't be fetched, the script falls back to the earlier raw scrape (`--raw-json`).
2. **ORIC brief.** Deans, chairs and co-chairs come from the brief (`FACULTIES` and `CHAIRS` in the script), and so do the ORIC team (`ORIC_STAFF`).
3. **HEC ORIC Self-Assessment Scorecard FY 2024-25.** PI, inventor and award-winner columns are read from sheets Index-B, Index-C and Index-D. The default path is `.local/hec_fy2024-25.xlsx`; pass `--excel` to use another file. Each name is matched against the scraped people:
   - first an exact normalized name match;
   - then a subset match (one name's words contain the other's);
   - then a fuzzy match (difflib ratio ≥ 0.88) inside the department named in the cell;
   - then a match against the email local part.

   A matched name is added to that person's `aliases`, and `source` becomes `website+excel`. An unmatched name that carries an NED department hint is added as a new person with `source=excel`. Names that look external (another university or a company) or have no department hint are skipped.

## Column notes

- `email_source=scraped` means the address appeared on the website. It is usually `@neduet.edu.pk` or `@cloud.neduet.edu.pk`, but about 29 people only list a personal address (gmail, yahoo and similar), and those are kept as published.
- `email_source=placeholder` means no address was found, so the script made one: `first.last@placeholder.neduet.edu.pk`, with a numeric suffix if needed to keep it unique.
- Role mailboxes such as `cid@`, `ced@`, `deancpe@` and `chaircsd@` are never assigned to a person.

## Re-running

From the backend root:

```bash
python -I tools/build_directory.py                       # live fetch (~1 s delay per request, retries)
python -I tools/build_directory.py --cache-dir /tmp/nedcache   # cache HTML, reuse on later runs
python -I tools/build_directory.py --offline --cache-dir /tmp/nedcache
python -I tools/build_directory.py --excel "path/to/scorecard.xlsx" --out org/seed
```

- Requests uses `requests` if it is installed, otherwise `urllib`.
- The Excel merge needs `openpyxl` and is skipped without it.
- The NED subdomains send an incomplete TLS chain. Certificate verification is turned off only for these public read-only pages.
- At the end the script prints counts per department, the number of placeholders, the Excel matched/added/skipped counts, and the result of the FK check.

## Profile photos

Faculty portraits are scraped from the department pages by `tools/scrape_photos.py`. Each one is resized to a 400px JPEG.

- **Where the files live:** `media/people/avatars/seed/<email-local>.jpg`. `media/` is git-ignored, so the photos are **not in git**.
- **What is in git:** only the `photo` column of `people.csv`, which holds each file name.
- **On a server:** copy the `seed/` folder to `<MEDIA_ROOT>/people/avatars/seed/` (in prod, `/root/ned_oric_backend/prod/media/people/avatars/seed/`). Then run `seed_oric` or `import_directory`.
- **How the import uses them:** `import_directory` / `seed_oric` links each file as the person's avatar in place, without copying. Rows whose file is missing are skipped, so the seed still works without the photos. A photo a person uploaded themselves is never replaced.

```bash
python -I tools/scrape_photos.py --cache-dir /tmp/nedcache   # run after build_directory.py (it rewrites people.csv)
python -I tools/scrape_photos.py --force                     # re-download everything
```

A photo is paired with a person in one of two ways. If the image's file name spells the person's name, that match is used. Otherwise the scraper takes the nearest name in the page's layout direction, which it learns from the file-name matches on that page. Generic placeholders are dropped: silhouettes, "image not available" tiles, and any image shared by several people. People without a portrait keep their initials. The departments with no photos on their site are SWE, EMS, EQD, ESD and TIEST.
